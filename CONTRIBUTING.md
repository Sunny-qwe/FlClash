# Contributing

Concord does not accept pull requests.

Report bugs and suggest changes through GitHub issues. A bug report should include:

- the Concord release or commit;
- the platform and how Concord runs there (on its own, or inside a host application);
- a minimal configuration that shows the problem, with servers, passwords and keys removed;
- the log around the failure, and what you expected instead.

Report security problems privately as described in [SECURITY.md](SECURITY.md), not in an issue.
